3. INSTALLATION REQUIREMENTS
----------------------------
- Airspace ACARS MUST be installed exclusively into your official Microsoft Flight
  Simulator "Community" directory (e.g.: ...\Packages\Community).
- Installing into an incorrect folder will prevent MSFS from loading the widget.
- Requires Parallel 42 Flow Pro installed in your simulator.

4. UPDATES AND SIMULATOR PROCESS LOCK
-------------------------------------
Before installing updates, Microsoft Flight Simulator MUST BE CLOSED. If the
simulator is running, Flow script files will be locked by Windows, leading to
failed updates or file corruption.

5. VIRTUAL AIRLINE (VA) CONNECTIVITY
------------------------------------
Airspace ACARS connects to the Airspace network using Device Code OAuth. Access
tokens are stored locally in your Flow datastore. Do not share your authorization
credentials or device codes with third parties.
